# Day 25 Assignment: Triggers

Use **hr.employees** and **hr.departments**. Create an audit table and triggers in your schema if you cannot modify HR. Prefer a copy table (e.g. hr_emp_backup) for trigger targets to avoid altering production.

---

## Part 1: Practice Questions (With Answers and Explanations)

### Question 1
Create an **AFTER UPDATE** trigger on **hr.employees** (or a copy) that fires when **salary** is updated. Log **employee_id**, **old salary**, **new salary**, and **changed date** to an audit table. Use :OLD and :NEW. (Create the audit table first.)

**Answer:**

```sql
CREATE TABLE emp_salary_audit (
  audit_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  employee_id NUMBER(6),
  old_salary NUMBER(8,2),
  new_salary NUMBER(8,2),
  changed_date DATE DEFAULT SYSDATE
);

CREATE OR REPLACE TRIGGER trg_emp_sal_audit
AFTER UPDATE OF salary ON hr.employees
FOR EACH ROW
WHEN (OLD.salary != NEW.salary)
BEGIN
  INSERT INTO emp_salary_audit (employee_id, old_salary, new_salary)
  VALUES (:NEW.employee_id, :OLD.salary, :NEW.salary);
END;
/
```

**Explanation:** AFTER UPDATE OF salary runs after the row is updated. FOR EACH ROW gives :OLD and :NEW. WHEN avoids logging when salary did not actually change. Insert into the audit table using :OLD.salary and :NEW.salary.

---

### Question 2
Create a **BEFORE INSERT** trigger that **defaults** **department_id** to 50 when it is NULL (only on insert). Use :NEW.department_id.

**Answer:**

```sql
CREATE OR REPLACE TRIGGER trg_emp_dept_default
BEFORE INSERT ON hr.employees
FOR EACH ROW
WHEN (NEW.department_id IS NULL)
BEGIN
  :NEW.department_id := 50;
END;
/
```

**Explanation:** BEFORE INSERT allows modifying :NEW. When department_id is NULL, set :NEW.department_id := 50. Only fires on INSERT; WHEN clause restricts to NULL department_id.

---

### Question 3
Create a **BEFORE UPDATE** trigger that **prevents** a **salary decrease**. If :NEW.salary < :OLD.salary, raise an error (RAISE_APPLICATION_ERROR).

**Answer:**

```sql
CREATE OR REPLACE TRIGGER trg_emp_no_sal_decrease
BEFORE UPDATE OF salary ON hr.employees
FOR EACH ROW
WHEN (NEW.salary < OLD.salary)
BEGIN
  RAISE_APPLICATION_ERROR(-20002, 'Salary cannot be decreased.');
END;
/
```

**Explanation:** BEFORE UPDATE allows rejecting the change. WHEN (NEW.salary < OLD.salary) fires only when salary is being reduced. RAISE_APPLICATION_ERROR aborts the update.
